Connected-store commerce

Let an agent find the product. Keep checkout on your store.

Catalog search, offer lookup and signed cart handoff form a separate connected-store surface. These tools do not grant Release Gate access and do not turn a public preflight into a transaction.

READ-ONLY DISCOVERY · MERCHANT-HOSTED CHECKOUT

Three narrow tools with a clear handoff.

01 / SEARCH

Search catalog

Return matching public products from a connected WooCommerce feed. No inventory is reserved.

02 / OFFER

Fetch an offer

Read the current public price and availability for one product. The merchant remains the source of truth.

03 / CART

Create cart handoff

Produce a short-lived signed URL that opens the merchant's checkout. AgentReady does not collect payment credentials.

The transaction boundary stays visible.

AgentReady may do

  • Read an explicitly connected public feed
  • Return product and offer identifiers
  • Sign a scoped, expiring cart handoff

The merchant still does

  • Show the final cart and price
  • Collect buyer approval and payment
  • Own inventory, tax, fulfillment and refunds

Need a release decision instead? The Release Gate uses a different contract: public preflight first, then owner-authorized signed aggregate evidence. Commerce plans do not include or imply Release Gate entitlement.
