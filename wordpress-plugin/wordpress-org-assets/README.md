# WordPress.org listing assets

These files are prepared for the top-level `/assets` directory in the
WordPress.org SVN repository after the plugin is approved. They are deliberately
excluded from the distributable plugin ZIP.

- `icon.svg`, `icon-128x128.png`, `icon-256x256.png`
- `banner-772x250.png`, `banner-1544x500.png`
- `screenshot-1.png` through `screenshot-3.png`

The screenshots are composed from a disposable WordPress + WooCommerce harness
with the submitted plugin installed. No customer, order, payment, credential or
private store data appears in them.
